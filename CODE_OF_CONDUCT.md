# Code of Conduct

ReviewPilot aims to be a welcoming and respectful project. This code applies
to project spaces, including issues, pull requests, and other project
discussions.

## Expected behavior

- Treat people with respect and consideration.
- Give constructive feedback focused on the work, not the person.
- Be open to different experiences and perspectives.
- Keep discussions focused on improving the project.

## Unacceptable behavior

- Harassment, discrimination, personal attacks, or threats.
- Sharing another person's private information without permission.
- Trolling, deliberate disruption, or other conduct that makes project
  discussions hostile or unsafe.

## Reporting

Report conduct concerns privately to the repository maintainers through
GitHub. Do not use public issues for sensitive reports. Maintainers will
review reports and take appropriate steps to keep project spaces respectful.
